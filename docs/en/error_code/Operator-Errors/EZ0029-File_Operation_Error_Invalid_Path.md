# EZ0029 File\_Operation\_Error\_Invalid\_Path

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: file path, error cause.

```text
Input path %s is invalid. Reason: %s.
```

Error example:

```text
Input path ../aipp_ut_test_11.cfg is invalid. Reason: The file path contains invalid character '..'.
```

## Solution

Try again with a valid path.

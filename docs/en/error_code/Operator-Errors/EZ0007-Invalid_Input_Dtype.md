# EZ0007 Invalid\_Input\_Dtype

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter name, operator name or API name, incorrect data type, correct data type.

```text
Input parameter %s of %s has incorrect dtype %s. It should be %s.
```

Error example:

```text
Input parameter sink of aclnnFlashAttentionScore has incorrect dtype INT32. It should be FLOAT. 
```

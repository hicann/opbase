# EZ0006 Invalid\_Input\_Format

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter name, operator name or API name, incorrect format, correct format.

```text
Input parameter %s of %s has incorrect format %s. It should be %s.
```

Error example:

```text
Input parameter x of BatchNorm has incorrect format NHWC. It should be NCHW. 
```

# EZ1002 Config\_Error\_Invalid\_Environment\_Variable

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: error stage, environment variable name.

```text
%s failed. Environment variable %s is not configured.
```

Error example:

```text
Load static bin json failed. Environment variable ASCEND_OPP_PATH is not configured.
```

## Solution

Reset the environment variable by referring to the Environment Variable Reference.

# EZ1012 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter value, parameter name, expected value.

```text
Value %s for parameter %s is out of range, it should be smaller than %s.
```

Error example:

```text
Value 98 for parameter index is out of range, it should be smaller than 1.
```

## Solution

Please adjust the parameter value as prompted in the error message.
